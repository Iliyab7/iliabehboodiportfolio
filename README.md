# پورتفولیوی ایلیا

سایت حرفه‌ای معرفی مهارت، سوابق و نمونه‌کار.

Next.js app، components، data و public.

مرجع این کپی `Iliyab7/iliabehboodiportfolio` است. ساختار داخلی محصول حفظ شده و workflowهای قبلی در `docs/migration/inherited-workflows/` نگهداری می‌شوند؛ deploy خودکار این کپی هنوز فعال نیست.

داده، secret و هویت provider در backup خصوصی و تنظیمات host نگهداری می‌شود. `project.manifest.json` شناسه ثابت محصول را دارد. قبل از اجرای setup، migration دیتابیس، clasp push یا reconnect، قرارداد اتصال و نتیجه QA را در governance بخوانید.

برای شروع و آزمون، دستورهای موجود در README محصول و package/script اصلی را استفاده کنید؛ این مهاجرت تکنولوژی و رفتار محصول را عوض نمی‌کند. وضعیت Local/Preview/Live جداگانه در registry ثبت می‌شود.
